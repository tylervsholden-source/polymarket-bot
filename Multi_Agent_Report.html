1. Sistem Mimarisi

Bot, 60 saniyelik döngülerle çalisan bir multi-agent orchestration sistemi kullanir. Her döngüde 3 bagimsiz agent koordineli çalisarak trade kararlari üretir. Hybrid iletisim modeli: Research ve Signal agent paralel çalisir, sonuçlari birlestirilir, ardindan Reviewer agent sirali olarak her sinyali degerlendirir.

2. Agent Görev Dagilimi

ResearchAgent SignalAgent ReviewerAgent
Piyasa durumu, whale aktivitesi, smart money, regime tespiti, on-chain veriler, sentiment analizi 6-model Bayesian pipeline: Bayesian + Edge + Spread + Stoikov + Kelly + Monte Carlo Claude API ile her trade önerisi APPROVE / VETO / REDUCE. API yoksa rule-based fallback

4. Yeni Özellikler

Confluence Score: Bagimsiz sinyallerin (edge, whale, smart money, regime, volume) ne kadar ayni yönde oldugunu 0-1 arasi ölçer. >0.7 yüksek güven, <0.4 düsük güven.

Risk Flag Sistemi: COUNTER_REGIME, WHALE_OPPOSITION, RSI_OVERBOUGHT/OVERSOLD, REGIME_OVEREXTENDED, LOW_VOLUME, THIN_EDGE otomatik tespit edilir.

Reviewer Veto: NO direction + edge <0.15 otomatik VETO. 3+ risk flag REDUCE (%50). RSI extreme + düsük confluence VETO.
